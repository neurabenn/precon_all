precon_all — Process Flow (Dev Table)

Preclinical / animal cortical surface reconstruction  ·  driver: surfing_safari.sh

Modeled on FreeSurfer’s ReconAllDevTable. Each module (-r precon_1 … precon_art) is the analogue of recon-all -autorecon1/2/3; within it, steps run top-to-bottom. Commands are the real invocations from the repo (bin/, bin/group_scripts/, utils/), with the source file and line noted on each step band. Run with surfing_safari.sh -i <T1.nii.gz> -r precon_all -a <animal>. ?h = lh / rh.

Toolkit FS FreeSurfer FSL FSL ANTS ANTs AFNI AFNI WB Workbench

Branch points (either/or) are marked [FNIRT]/[ANTs] for extraction and [FAST]/[Atropos] for segmentation. ${ANTSPATH} / $FSLDIR/bin prefixes omitted for readability.
