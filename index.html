precon_all

Preclinical / animal cortical surface reconstruction  ·  driver: surfing_safari.sh

An animal surface generation pipeline, adaptable to multiple species. Modeled on FreeSurfer's recon-all, mixing FreeSurfer, FSL, ANTs, AFNI, and Connectome Workbench under the hood. The example used throughout is the pig, as it's what the pipeline has been used for the most. Source: github.com/neurabenn/precon_all.

Toolkit FS FreeSurfer FSL FSL ANTS ANTs AFNI AFNI WB Workbench
Setup Clone the repo and point $PCP_PATH at it

Clone the repository, then set an environment variable pointing to it: $PCP_PATH.

Run — single subject, new species Build five masks, drop them in a masks/ folder

Create five masks:

  1. Brain mask — brain_mask.nii.gz
  2. Left hemisphere mask — left_hem.nii.gz
  3. Right hemisphere mask — right_hem.nii.gz
  4. Subcortical mask, covering the corpus callosum, everything beneath it, and the ventricles — the area filled in by the medial wall — sub_cort.nii.gz
  5. Non-cortical mask, covering everything to exclude from the final surface — non_cort.nii.gz

Place all five in a folder named masks in the working directory alongside your image, then run:

surfing_safari.sh -i <my_T1.nii.gz> -r precon_all -a masks
Run — high-throughput, standard template Per-animal standards/ directory for repeated runs

Create a new directory per animal at $PCP_PATH/standards/<your_animal>, containing:

  • extraction/ — <animal>_temp.nii.gz, brain_mask.nii.gz, <animal>_brain.nii.gz
  • fill/ — left_hem.nii.gz, right_hem.nii.gz, sub_cort.nii.gz, non_cort.nii.gz
  • seg_priors/ (optional) — csf.nii.gz, gm.nii.gz, wm.nii.gz. Recommended when available; the pipeline runs without them but may need more manual intervention posthoc.

Then run:

surfing_safari.sh -i <my_T1.nii.gz> -r precon_all -a <your_animal>
Correcting white & pial surfaces Standard FreeSurfer-style hand edits, as a NIfTI

precon_all is built on FreeSurfer. To edit a surface, edit wm.nii.gz and save it in the subject's /mri/ folder as wm_hand_edit.nii.gz — the same process used to correct pial surfaces in human FreeSurfer, except the file needs to be a NIfTI.

Other options Flags for surfing_safari.sh
FlagEffect
-a <animal>Animal model — must be the name of a folder in $PCP_PATH/standards/, e.g. $PCP_PATH/standards/pig
-nNo brain extraction — use a previously extracted brain; only runs linear transforms
-eBrain extraction with ANTs instead of FNIRT, using template space
-v <res>Downsample individual surfaces to a given resolution in HCP space
-t <thresh>Segmentation threshold. Default 0.5 for FAST, 0.1 for ANTs
-sSegment with ANTs AtroposN4 instead of FAST. Default threshold 0.1
-gOptional, default none. Percentile within the gray matter mask at which to place the pial boundary — should only be used in precon_3 refinement
-LLeft hemisphere only
-RRight hemisphere only
-hHelp

Compulsory: -i <T1 image> image to reconstruct the surface from, and -r <process> which process to run (precon_all, precon_1, precon_2, precon_3, precon_art).

Example: surfing_safari.sh -i <T1.nii.gz> -r precon_all -a pig

Modules -r precon_1 … precon_art
ModuleScope
precon_allReconstructs the cortical surface from a single whole-head image
precon_1Brain extraction only
precon_2Denoising, segmentation, WM fill, surface generation
precon_3WM filling and surface generation only
precon_4Downsamples the output of a previous run (-v mandatory)
precon_artVisualization / figures only, includes the non_cort mask. Run only after precon_2. Not meant to give any statistics or information on the surface — visualization purposes only.
Installation FreeSurfer 6+ · FSL 6+ · ANTs 2.3.5+ · Workbench 1.5.0+

Requires FreeSurfer 6+, FSL 6+, ANTs 2.3.5+, and Connectome Workbench 1.5.0+, each installed per its own instructions and available on your bash profile. Clone the repo and point $PCP_PATH at it.

Docker Prebuilt image on Docker Hub, or build locally

Pull the prebuilt image — docker pull neurabenn/precon_all:latest (Apple Silicon / other arm64: add --platform=linux/amd64). The image does not include a FreeSurfer license; mount your own fs_license.txt at runtime. If pulling doesn't work, build locally from precon_alldockerfile. Also runnable on HPC clusters via Singularity.

Runtime Typical: 2–5 hours per subject

Most species finish in 2–5 hours; highly gyrified or very large brains can take longer. Because parcellation isn't run and segmentation is limited to gray/white/CSF, kill the process if it exceeds 18 hours.
